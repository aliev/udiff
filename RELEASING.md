# Releasing

μdiff uses cargo-dist, following the release setup used by
[aliev/baker](https://github.com/aliev/baker). A version tag builds archives and
installers, creates a GitHub Release, and updates
[aliev/homebrew-tap](https://github.com/aliev/homebrew-tap).

## One-time GitHub setup

Create a fine-grained personal access token that can write repository contents
in `aliev/homebrew-tap`. Add it to the μdiff repository as an Actions secret
named `HOMEBREW_TAP_TOKEN`.

The generated release workflow uses the repository-provided `GITHUB_TOKEN` for
the μdiff release itself. No additional secret is required for release
artifacts.

## Release

1. Update the version in `udiff/Cargo.toml` and `uwatch/Cargo.toml` — both
   packages are released in lockstep under a single tag — then run
   `cargo update -w`.
2. Move the relevant entries in `CHANGELOG.md` from Unreleased to the new
   version and date.
3. Run the full verification suite:

   ```bash
   cargo fmt --all --check
   cargo clippy --workspace --all-targets -- -D warnings
   cargo test --workspace --locked
   cargo dist plan
   ```

4. Merge the release changes to `main`.
5. Create and push the matching version tag:

   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```

The Release workflow publishes the GitHub artifacts first and updates
`Formula/udiff.rb` in the tap only after the release succeeds. Prerelease
tags do not update the stable Homebrew formula.

## Keeping the release workflow up to date

`.github/workflows/release.yml` is generated by cargo-dist and is verified by
`dist plan` on every pull request. The action versions it pins are chosen by
cargo-dist, so Dependabot pull requests that bump them make the file diverge
from what cargo-dist would generate and the `plan` check fails.

Close such pull requests and take the update through cargo-dist instead:

```bash
cargo install cargo-dist --locked   # or the version you want
# bump cargo-dist-version in dist-workspace.toml to match, then
dist generate
```

Dependabot updates to `.github/workflows/ci.yml`, which is hand-written, can be
merged normally.
